  • Two loss signals, two severities: 3 dup ACKs = mild (later packets still arrive → halve cwnd, keep going). Timeout = severe (nothing gets through → cwnd = 1, restart slow start).
  • ssthresh remembers where congestion happened (cwnd/2), so next time growth turns cautious before the old failure point → sawtooth.
  • Fast recovery's inflate (+1 MSS per dup ACK) keeps the pipe full while the missing segment is retransmitted; the cumulative new ACK deflates back to ssthresh.
  • ssthresh uses max(cwnd/2, 2) here — real TCPs floor the window at ~2 MSS.
  • Tahoe mode: no fast recovery — 3 dup ACKs is treated exactly like a timeout.
